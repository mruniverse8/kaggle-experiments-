# Data Folder

This folder stores local project data for Dogs vs Cats.

Current local dataset path (inside this repo):
- `dogs-vs-cats/`

Dataset contents:
- `train/` (25,000 labeled images)
- `test1/` (12,500 unlabeled images)
- `sampleSubmission.csv`
- source zip files

Note:
- Raw data is intentionally ignored by Git via the repository `.gitignore`.
- Keep data local; commit only code/config/docs/notebook artifacts.
